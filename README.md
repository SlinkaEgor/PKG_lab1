## 3. Краткое описание цветовых моделей

### 3.1 RGB

RGB (Red, Green, Blue) — аддитивная цветовая модель, в которой цвет формируется смешением трёх основных компонентов:

- **R** — красный;
- **G** — зелёный;
- **B** — синий.

Диапазон:

```text
R, G, B ∈ [0; 255]
```

RGB широко используется в компьютерной графике, мониторах и цифровых изображениях.

### 3.2 CMYK

CMYK — субтрактивная цветовая модель, используемая преимущественно в полиграфии.

Модель состоит из:

- **C** — Cyan;
- **M** — Magenta;
- **Y** — Yellow;
- **K** — Key/Black.

Диапазон:

```text
C, M, Y, K ∈ [0; 100] %
```

В приложении предусмотрены два метода формирования чёрной компоненты:

- **GCR (Gray Component Replacement)**;
- **UCR (Under Color Removal)**.

### 3.3 HSV

HSV (Hue, Saturation, Value) представляет цвет через оттенок, насыщенность и значение яркости.

Компоненты:

- **H** — Hue, оттенок;
- **S** — Saturation, насыщенность;
- **V** — Value, значение яркости.

Диапазоны:

```text
H ∈ [0; 360]°
S ∈ [0; 100] %
V ∈ [0; 100] %
```

## 7. Динамические градиенты ползунков

Для ползунков реализованы динамические цветовые градиенты.

Градиент показывает, каким будет итоговый цвет при изменении конкретной компоненты, при этом остальные компоненты сохраняются неизменными.

Например, для RGB при фиксированных G и B изменение ползунка R показывает изменение итогового цвета от минимального до максимального значения R.

Градиенты автоматически пересчитываются при изменении текущего цвета.

## 8. Алгоритмы преобразования

### 8.1 RGB → CMYK

Значения RGB нормализуются:

```text
r = R / 255
g = G / 255
b = B / 255
```

Затем вычисляются компоненты CMY:

```text
C = 1 - r
M = 1 - g
Y = 1 - b
```

#### GCR

Чёрная компонента:

```text
K = min(C, M, Y)
```

Цветные компоненты:

```text
C' = (C - K) / (1 - K)
M' = (M - K) / (1 - K)
Y' = (Y - K) / (1 - K)
```

Результат переводится в проценты.

#### UCR

Определяется исходная чёрная составляющая:

```text
K_raw = min(C, M, Y)
```

При превышении установленного порога рассчитывается:

```text
K = K_raw * (K_raw - threshold) / (1 - threshold)
```

После этого:

```text
C' = C - K
M' = M - K
Y' = Y - K
```

В приложении используется порог UCR 50%.

---

### 8.2 CMYK → RGB

Значения CMYK переводятся в диапазон `[0; 1]`:

```text
C = C / 100
M = M / 100
Y = Y / 100
K = K / 100
```

Затем:

```text
R = 255 · (1 - C) · (1 - K)
G = 255 · (1 - M) · (1 - K)
B = 255 · (1 - Y) · (1 - K)
```

---

### 8.3 RGB → HSV

RGB нормализуется:

```text
r = R / 255
g = G / 255
b = B / 255
```

Определяются:

```text
max = max(r, g, b)
min = min(r, g, b)
Δ = max - min
```

Значение яркости:

```text
V = max
```

Насыщенность:

```text
S = Δ / max
```

если `max ≠ 0`.

Оттенок определяется в зависимости от максимальной компоненты RGB и приводится к диапазону:

```text
H ∈ [0; 360]°
```

---

### 8.4 HSV → RGB

Оттенок разделяется на шесть секторов:

```text
0–60°
60–120°
120–180°
180–240°
240–300°
300–360°
```

В зависимости от сектора вычисляются промежуточные значения, после чего формируются R, G и B.

Полученные значения переводятся обратно в диапазон:

```text
[0; 255]
```

## 9. Синхронизация моделей

При изменении любой компоненты приложение автоматически пересчитывает остальные модели.

При изменении RGB:

```text
RGB
 ↓
CMYK
 ↓
HSV
```

При изменении CMYK:

```text
CMYK
 ↓
RGB
 ↓
HSV
```

При изменении HSV:

```text
HSV
 ↓
RGB
 ↓
CMYK
```

RGB используется как промежуточное представление при преобразовании между CMYK и HSV.
