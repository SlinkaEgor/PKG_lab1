# Color Model Converter

Приложение на PyQt6 для преобразования и визуального представления цветов в различных цветовых моделях.

Проект выполнен для варианта 7 и поддерживает работу с цветовыми моделями:

- CMYK
- RGB
- HSV

При изменении значения любого параметра остальные цветовые модели пересчитываются автоматически.

## Возможности

- преобразование цветов между CMYK, RGB и HSV;
- ввод точных значений параметров;
- изменение значений с помощью ползунков;
- выбор цвета с помощью системного диалога выбора цвета;
- ввод цвета в HEX-формате;
- визуальное отображение выбранного цвета;
- автоматический пересчёт значений во всех моделях;
- ограничение допустимых значений параметров.
